# MAGTOPIA brand assets

- `logo.svg`: editable vector civic crest. An arched shield frames an M skyline, central spire, city gate, and small star. The palette is plum, blush, warm ivory, and muted gold.
- `city-day.jpg` / `city-night.jpg`: actual game screenshots, re-captured with `scripts/capture-home-city.mjs` using the district scene with depth of field and aerial perspective disabled for legibility.
- `city-stage-0.jpg` / `city-stage-1.jpg` / `city-stage-2.jpg`: the same native renderer and fixed camera, with authored building meshes progressively revealed. This is a layout illustration, explicitly not a recorded autonomous city history.
- `city-vision.jpg`: aspirational concept art generated with the built-in ImageGen tool; not an in-game screenshot. The homepage explicitly labels it and provides actual game imagery in a separate section. Original generated PNG remains in Codex generated images; a compressed copy is checked into this project.
