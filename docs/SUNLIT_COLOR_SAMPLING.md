## 校准方式

保留原图为色彩标准，不以重新生成的图像替换目标。Studio 校准场景应使用两排各三栋同类维多利亚联排商住建筑（砖墙、奶油石材、蓝灰坡屋顶、烟囱），设置一块开阔草地及路面，保留建筑真实投影。朝向需同时展示受光、背光立面。固定种子、太阳角度、相机和 DPR。

先关闭空气透视与景深，检查材质角色与光照：同向石材和砖墙若同时偏暗，调整光照；仅砖墙偏暗或偏褐，优先检查 brickRed/brickBrown 的分配和颜色。屋顶、石材、砖墙分别测量，不使用全屏统一曝光补偿。随后恢复原景深，再启用弱空气透视，并检查近远视角前景取色是否漂移。

当前砖墙的线性亮度差约为屋顶差距的两倍以上，说明统一曝光不是合适的补偿。这里的亮度比不能直接当作光照或材质乘数。

数据与复现脚本：`artifacts/palette-study/samples.json`、`artifacts/palette-study/sample.py`。这是取色诊断，不是新的视觉验收通过记录。

## 实施：Studio 校准与空气透视修正

入口：`/studio?mode=district&calibration=sunlit&worldTime=0.38&clock=0`。使用真实联排建筑生成器，近处两排各三栋，另两排作为远景深度参照；所有不透明建筑网格投影，平面逻辑坐标沿原球面投影流程处理。这个场景只在 Studio 显式选择时启用，不替换玩家城市。

空气透视改为 `max(0, dot(worldPosition - focus, viewDirection))`，从观察中心后方 18 单位起，125 单位处达到最大量；最大混合量 10%，取消额外阴影提亮和对比度压缩。雾色向白天天空蓝色倾斜，避免奶白。实例化网格世界坐标现在包含实例矩阵，防止按模板原点而非真实位置算雾。`aerialPerspective=0` 可关闭空气透视，`bokeh=0` 可关闭景深。

按原图区域取色分角色调整了砖红、砖棕、石材、板岩与草地，地面环境补光从偏土黄改为中性偏冷；三渲二强度降至 0.4，抬高中亮度分段，保留真实投影。没有把取样 HEX 当作材质输入直接复制，也未改变太阳轨迹。天空 shader 补上输出色彩空间转换，确保景深启停时直出与合成路径一致。

复现：

```sh
STUDIO_MODE=district STUDIO_CALIBRATION=1 STUDIO_TIME=0.38 node scripts/capture-sunlit-studio.mjs calibration-final
node scripts/check-aerial-studio.mjs
```

`STUDIO_BOKEH=0`、`STUDIO_AERIAL=0` 控制捕获时的效果开关。曾尝试解除浏览器帧同步以补测吞吐量，但未及时产出可用截图，已终止该诊断；没有采用其结果或保留其运行开关。

本轮 `aerial-check.json`：近景、远景分别比较空气透视开启和关闭时的固定前景地面区域，最大 RGB 通道差均为 0；这是选定前景区域的像素检查，并非整幅图逐物体证明。另有观察中心、前景、后景的相机后退/转向数学回归测试。

默认浏览器环境：空白页平均帧间隔约 33.33ms，调整前与调整后校准场景也约 33.33ms。当前证据表明存在约 30Hz 的帧调度上限；本轮没有将它计为 60fps 验收通过，也未修改系统电源/显示设置。
