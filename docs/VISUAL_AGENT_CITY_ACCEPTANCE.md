# Agent 城市视觉验收（2026-08-02）

入口：`/?mode=agentcity&view=1`。城市与 `Agent Intent District` 使用同一球面体素投影、贴球面等距相机和 Bokeh 景深；`view=1` 隐藏全部 UI，`time=evening` 使用傍晚光照。

本次场景重放无视觉 Agent 验收中的三街区、八建筑和完整道路/桥梁状态；视觉模型只用于建成后的检查，不参与 Agent 选址、设计确认或施工。

## 暂定评分

| 项目 | 评分 | 判断 |
|---|---:|---|
| 结构逻辑 | 7/10 | 无占地冲突，入口均接路，跨河连接存在；桥头引道和道路等级仍不合理 |
| 建筑语汇 | 8/10 | 红砖、浅石饰面、板岩屋顶、塔楼和连续窗节奏较可信 |
| 城市界面 | 4/10 | 街区过疏，缺少连续街墙、内院、广场与主次街道，整体更像乡间新镇 |
| 魔法辨识度 | 4.5/10 | 暖窗与少量紫光成立，但魔法功能、招牌和公共地标不足 |
| 道路/桥梁视觉 | 4/10 | 连通正确，但现代虚线沥青路不符合维多利亚伦敦；桥缺少栏杆、桥台和独立结构 |
| 地形与自然 | 7.5/10 | 河流、湖泊、高差与林地构成清晰；植被在城区边缘过密且切换突兀 |
| 综合 | 6/10 | 建筑单体已进入目标风格，城市组织和基础设施仍是主要短板 |

## 明显问题

1. 三个逻辑街区在全景中只形成东西两个建筑团块，中间由超长等宽道路连接；没有形成可读的第三街区中心。
2. Agent 过早跨河扩张，大片可建设土地没有形成连续街墙。应先在已有道路 1–3 格范围内填充，再允许创建远端 district anchor。
3. 所有道路使用相同的现代沥青、中心虚线和宽人行道。需要 `lane / local_street / avenue / bridge` 等道路等级及维多利亚石材、鹅卵石语言。
4. 桥只是抬高的普通道路。桥头东岸出现紧凑 S 弯，缺少至少 2 格直线引道；桥本体缺栏杆、桥台、桥墩或魔法承重构件。
5. 建筑名称中的 market、courtyard、yard 没有稳定映射为开放空间或服务入口，数个公共建筑表现为大体量矩形块。
6. 装饰几乎都使用 roof finial；魔法风格缺少按 program 区分的 hanging sign、炼金橱窗、温室、钟表机械、学院照明与公共空间焦点。
7. 西岸街区靠近世界边缘，背面直接面对地图边界，削弱完整城市感。选址应保留至少 2–3 格边界缓冲。
8. 植被避让建筑和道路已经正确，但密林紧贴建筑 parcel，缺少由铺地、围墙、后院到林地的城市边缘过渡。

## 已在验收中修复

动态体素建筑运行时改用 greedy surface batching。相同场景的渲染统计从约 3690 draw calls / 468 万 triangles 降至约 2208 draw calls / 119 万 triangles。

道路与植物已从验收场景中的 low-poly 渲染器迁移到状态驱动的体素渲染器：道路按实际 road/bridge 状态生成 0.125 世界单位体素并进行 greedy chunk 合批；植物使用同一体素材质系统，并对建筑、道路、桥梁和入口保留一格安全带。桥梁本轮只保证体素风格和路线正确，独立桥梁造型留待专项设计。

当前 API 黑盒验收不把桥梁造型、方格地图的 S 急弯、建筑功能性辨识度作为失败项；这些项目在建造与路网接口稳定后分别专项提升。

## 下一轮建议验收门槛

- 至少一个连续 6–10 栋的街墙；
- 三个街区各有明确中心、边界和道路入口；
- 远端新区须通过发展阶段或最大空置路段约束；
- 桥水段保持直线，两岸各至少 2 格直线引道；
- 本地街道使用石材/鹅卵石，只有主干道允许中心标线；
- 每个 program 产生可区分的 facade、sign、yard/court 或 roof landmark；
- 所有建筑入口仍处于 gateway 可达路网；
- 视觉验收视角下不存在建筑/道路/树木相交；
- 桌面目标 draw calls 低于 800，近景稳定帧时间低于 20ms。
